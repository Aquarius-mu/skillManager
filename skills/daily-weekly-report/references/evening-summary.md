# 工作日一天总结（晚间 19:00）— 详细流程与规则

与早间梳理互补：早间看"昨天做了什么 + 今天做什么"，晚间看"今天实际做了什么 + 还有什么没收尾"。

## 输入数据

```bash
# 采集今天 00:00 ~ 当前时刻的全部数据
python scripts/collect_all.py --date <今天YYYY-MM-DD> --out <tmp>/today.json
```

`today.json` 含：messages（相关消息）、calendar（今日日程）、minutes（妙记）、documents（文档活动），以及补采的 approvals（审批）/ mails（邮件）/ vc_meetings（视频会议）/ task_activity（任务活动），各带 `covered` 标记。

再补任务数据：
```bash
lark-cli task +get-my-tasks --complete=false --due-start <今天>T00:00:00+08:00 --due-end <今天>T23:59:59+08:00   # 今日到期未完成
lark-cli task +get-my-tasks --complete=true --created_at <昨天>T00:00:00+08:00                                  # 近两天新建/完成
```

## 总结视角（四个问题）

1. **今天完成了什么**：从 `sent_by_me` 消息 + 文档编辑活动 + 发版卡片聚类出实际产出（结果导向）。
2. **今天推进了什么**：进行中事项的最新状态变化（线修节点、发版进度、方案确认）。
3. **还有什么没收尾**：今天被 @ 但未回复的、承诺了但没做完的、今日到期但没完成的任务。
4. **明天要接什么**：从今天的对话中识别出的明日约定（如"明天问对面""周五10点前到"）。

## 卡片结构（sections 顺序固定）

```
sections[0] 问候 + 一句话总述（今天 N 个活跃会话、M 条相关消息）
sections[1] ## ✅ 今日完成
            按事项列，每条带结果（修复了X / 发版完成 / 方案确认）
sections[2] ## 🔄 今日推进中
            事项 + 当前状态 + 卡点（如有）
sections[3] ## ⏳ 未收尾事项
            今日到期未完成任务（带链接）/ 未回复的 @ 消息 / 承诺未兑现项
            （没有就写"今日事项均已收尾 ✅"）
sections[4] ## 📌 明日待接
            从今日消息中识别出的明日约定/到期任务
footer     一句话收尾（辛苦程度/节奏评价）
```

## 写作规则

- **只写今天真实发生的**：以消息时间戳为准，不把昨天的事算进来。
- **完成与否看证据**：有"好了/提交了/发好了/验证通过"类确认才算完成；只有"我看下/处理中"算推进中。
- **未回复检测**：别人 @ 我（mention_me）且其后同会话没有我的回复 → 列入未收尾。
- **不过度拔高**：帮同事解答一个问题、审阅一段代码也是工作，如实写。
- 文档活动（edited/created）作为"完成/推进"的佐证，注意"打开过"不等于"完成了"。
